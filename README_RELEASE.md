# Release Information

This repository contains the code and documentation for the cabbage ADPV project.

## Dataset

The released dataset is available at:

https://github.com/Stevensen1226/cabbage-phenotyping/releases/tag/v1.0.0

## Source and Documentation

The repository includes:

- preprocessing, segmentation, instance clustering, trait, and evaluation code;
- fixed train/validation/test split manifests;
- final paper tables and figures;
- documentation and reproducible result files.

## Notes

Model checkpoints, raw point-cloud data, caches, and other large binary files are not committed to Git history. Use the GitHub Releases for downloadable archives.
