# 4 实验与结果分析

## 4.1 数据集与评价指标

### 4.1.1 数据集

实验数据集包含 23 块甘蓝田地点云，由田间激光扫描设备采集。每块点云均经过人工逐点标注，提供语义标签（0=背景，1=甘蓝）和实例标签（0=背景，≥1=植株编号）。数据集按实例数量分层随机划分为验证集和测试集：验证集包含 4 块田地共 60 个植株实例，测试集包含 6 块田地共 102 个植株实例。所有报告结果均基于测试集。

### 4.1.2 评价指标

本文从实例分割精度和表型参数估计两个层面评估方法性能。

**实例分割指标（核心）：**
- **实例精确率（Prec）**：$\text{Prec} = TP_{\text{inst}} / N_{\text{pred}}$，衡量预测实例中正确匹配的比例。
- **实例召回率（Rec）**：$\text{Rec} = TP_{\text{inst}} / N_{\text{gt}}$，衡量真实实例中被成功检出的比例。
- **实例 F1 分数**：精确率与召回率的调和均值。
- **实例平均 IoU（实例 mIoU）**：成功匹配的预测-真实实例对之间的平均交并比。
- **语义 mIoU**：语义分割（甘蓝/背景二分类）的类别平均 IoU。

匹配标准要求预测实例与真实实例的 IoU ≥ 0.5 且为一对一匹配。

## 4.2 消融实验

### 4.2.1 实验设计

为独立量化 GIDM 各组件（异常簇检测 GD、骨架切割 SC、自适应阈值 AT、碎片回并 MB）的贡献，我们在 **RandLA‑Net + Watershed 3D** 组合（测试集，14 块田地）上进行消融实验。选择该组合的原因在于：RandLA‑Net 为纯语义主干（无偏移分支），Watershed 3D 基线对粘连植株存在严重欠分割，从而为各组件评估提供最大的动态范围。

我们定义六种配置，如表 1 所示。“Full GIDM”包含全部四个模块；每种消融配置仅移除一个组件，其余保持不变；“Baseline”为原始 Watershed 3D，不施加任何后处理。

**表 1  消融实验配置**

| 配置 | 异常检测 | 骨架切割 | 自适应阈值 | 碎片回并 | 说明 |
|:---|:---:|:---:|:---:|:---:|:---|
| **Full GIDM** | ✓ | ✓ | ✓ | ✓ | 完整的几何感知解耦 |

### 4.2.3 组件贡献分析

我们通过移除某一组件后 Full GIDM 的性能下降（ΔF1 与 ΔMAE(Count)）来量化各组件的独立贡献，见表 3。

**表 3  各组件移除后的性能变化**（正值表示该组件带来的改进）

| 移除组件 | ΔF1 | ΔMAE(Count) | 解读 |
|:---|:---:|:---:|:---|
| **自适应阈值（−AT）** | **+0.112** | +0.214 | **对 F1 影响最大**。召回率从 0.853 骤降至 0.695，因为超大簇（$D>0.60$ m）几乎必然包含多株，将波谷深度阈值从 0.90 放宽至 0.98 是分离此类粘连大簇的关键。 |
| **异常检测（−GD）** | +0.045 | **+0.500** | **对计数精度影响最大**。跳过异常检测后，所有簇（包括正常球形单株）均被强制切割，精确率从 0.803 降至 0.756，计数 MAE 从 1.857 升至 2.357。该模块有效防止对健康单株的过度分割。 |
| **骨架切割（−SC）** | +0.036 | −0.286 | 移除后 F1 降低 0.036，但 MAE 反而下降（1.857→1.571）。骨架切割显著提升召回率（0.800→0.853），但会引入轻度过分割，因此对计数精度产生轻微的负面影响。 |
| **碎片回并（−MB）** | −0.007 | +0.072 | F1 几乎不变（0.825→0.832）。MB 主要抑制过分割并减少计数误差（MAE 增加 0.072），但其对 F1 的净贡献较小，与骨架切割形成互补。 |

综合而言，四个组件构成 **“检测—切割—回并”** 闭环：
- **异常检测** 与 **自适应阈值** 是核心组件——前者决定“是否切割”（防止过分割，贡献 +0.500 MAE 改进），后者决定“切割强度”（贡献 +0.112 F1 增益）。
- **骨架切割** 是召回率提升的主要来源（+0.053），但伴随一定的过分割副作用。
- **碎片回并** 作为安全网，补偿骨架切割引入的过分割。

完整 GIDM 将 F1 从基线的 0.530 提升至 0.825（绝对 **+0.295**，相对提升 55.7%），并将计数 MAE 从 4.929 降至 1.857（**降低 62.3%**）。

全部实验中 **最高 F1 = 0.978**，由 **PointGroup (IACH) + MeanShift + GIDM** 取得，相比同配置无 GIDM 版本（F1=0.743）提升 **+0.235**。次优结果为 PointGroup (IACH) + Watershed 3D + GIDM（F1=0.974）和 PointGroup (IACH) + HDBSCAN + GIDM（F1=0.965）。

## 4.4 讨论与分析

### 4.4.1 GIDM 的核心贡献

4.3.1 节结果表明，GIDM 在所有 18 种实验配置上均一致提升实例 F1，平均 ΔF1 为 **+0.328**，最大 **+0.666**。由于各组对比中上游语义分割和基础聚类完全相同，增益完全归因于 GIDM 模块。

- **对弱聚类补偿最强**：HDBSCAN 在高度重叠植株上几乎失效（F1≈0.11–0.14），经 GIDM 后提升至 0.78–0.80。这是因为 GIDM 的骨架密度波谷切割直接作用于几何信号（主轴密度分布），绕过了 HDBSCAN 较差的亲和性估计。
- **对强聚类仍有稳定增益**：即使基础组合如 PointGroup (IACH) + MeanShift 已取得 F1=0.743，GIDM 仍将其推至 0.978（+0.235），证明其在保留正常单株的同时，能够进一步精化异常粘连簇。
- **计数误差大幅降低**：所有配置的计数 MAE 下降 77–90%，直接回应了植物实例分割中最实际的瓶颈——因植株重叠导致的严重漏计数。

### 4.4.2 跨主干网络与聚类算法的泛化性

GIDM 展现出 **即插即用** 的兼容性，体现在：
- **四种语义主干**：RandLA‑Net（纯语义）、PointGroup（带偏移提案，三种模式）、PointNeXt‑L（现代 PointNet++ 变体）、PointNet2（经典）。无论架构细节如何，GIDM 均带来正向增益。
- **三种聚类范式**：MeanShift（密度梯度）、HDBSCAN（层次密度）、Watershed 3D（距离变换）。GIDM 均能进一步提升，且对最弱的聚类器（HDBSCAN）增益最大。

18 组实验中，GIDM **100% 取得正向提升**，无任何退化。该鲁棒性源于其仅依赖原始几何信息（PCA 主轴、局部密度分布），与上游模块的内部表示或学习参数无关。

### 4.4.3 骨架切割的不可替代性

“局部聚类”步骤已在基础聚类后进行补充聚合，但仍有大量粘连簇无法分离——因为它们在空间上连续，且无明显的密度间隙。纯距离或密度方法无法区分物理接触的植株。

GIDM 的突破在于 **基于 PCA 的密度波谷切割**：通过沿主伸长方向分析密度分布，识别相邻植株之间的“颈部”（密度波谷），而非依赖绝对空间距离。这种几何推理是常规聚类算法无法实现的，因此 GIDM 并非简单的后处理启发式，而是实质性的增强。

### 4.4.4 局限性

尽管效果显著，GIDM 仍存在若干局限：
1. **点密度要求**：骨架波谷检测需要足够的采样密度（>100 点/m²），在极稀疏区域噪声可能干扰密度分布。
2. **作物特异性阈值**：异常检测参数（$D=0.60$ m 尺寸阈值，$r=1.60$ 长宽比阈值）针对甘蓝品种标定，迁移至其他形态不同的作物时需重新校准。
3. **单向切割**：递归切割仅沿第一主成分方向进行，对于具有多个接触方向的复杂交错排列，可能需要多方向切割策略——这留待未来工作探索。
