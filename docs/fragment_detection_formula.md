# 碎片候选区域识别

骨架切割在将粘连多株簇拆分后，可能产生两类退化碎片：其一为切割面落入稀疏叶片间隙所导致的过分割碎片，其二为密度波谷误判所引入的孤立噪声点簇。因此，在骨架切割之后须识别并清理碎片候选区域。

首先，识别当前实例集合 $\mathcal{I} = \{I_1, I_2, \dots, I_M\}$ 内的所有碎片候选。具体而言，对每个实例 $I_j$，计算其点数量 $n_j = |I_j|$ 以及沿第一主方向的投影长度 $L_j$（即主轴跨距 $L_1$），满足下述任一条件的实例被标记为碎片候选区域：

$$n_j < \theta_n \quad \text{or} \quad L_j < \theta_L \tag{11}$$

式中：$\theta_n = 1500$ 为点数阈值，$\theta_L = 0.15\ \text{m}$ 为长度阈值，二者均依据甘蓝单株的先验形态尺度直接给定——正常甘蓝单株的点数通常远超 $1500$、主轴跨距通常大于 $0.15$ m，因此满足上述条件的实例几乎可以确定为切割碎片或噪声点簇。

对于主轴跨距 $L_j < \theta_L$ 的碎片 $I_j$，若其质心 $\bar{\mathbf{p}}_j$ 附近存在其他实例 $I_k$，且同时满足质心距离约束与主轴夹角约束，则将碎片 $I_j$ 并入实例 $I_k$：

$$\left\| \bar{\mathbf{p}}_j - \bar{\mathbf{p}}_k \right\| < \theta_d, \quad \angle\left( \mathbf{v}_1^{(j)},\ \mathbf{v}_1^{(k)} \right) < \theta_a \tag{12}$$

式中：$\mathbf{v}_1^{(\cdot)}$ 为对应实例的第一主方向；$\theta_d = 0.20$ m 为质心距离阈值，$\theta_a = 30^\circ$ 为主轴夹角阈值。距离约束保证碎片与目标实例在空间上邻近，夹角约束保证二者的延展方向一致，从而避免将本应独立的相邻植株错误合并。

在完成长度维度的回并后，进一步按点数清理残余碎片：点数量 $n_j < 500$ 的实例视为孤立噪声直接丢弃，点数量 $500 \le n_j < 1500$ 的实例视为小碎片并入质心距离最近的大簇：

$$\begin{cases}
\text{discard}, & n_j < 500 \\[2pt]
\text{merge to nearest}, & 500 \le n_j < 1500
\end{cases} \tag{13}$$

该两步清理与回并共同构成碎片优化机制，在抑制过分割的同时，避免粘连多株簇的欠分割。
