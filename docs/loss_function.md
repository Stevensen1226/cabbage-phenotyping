# 2.2.6 损失函数

在甘蓝田间点云语义分割任务中，点云类别分布存在严重不平衡：背景点（土壤、杂草及其他非植株结构）占据场景中的绝大多数，而甘蓝植株点仅占极小比例。若直接使用标准无加权交叉熵损失函数，网络会倾向于优先提升占比最大的背景类的分割精度，从而导致目标甘蓝植株的漏检和欠分割。为解决这一问题，本项目采用类别加权交叉熵损失函数，对少数类（甘蓝）赋予更高的惩罚权重：

$$L_{wCE} = -\frac{1}{N} \sum_{i=1}^{N} w_{y_i} \cdot y_i \log(\hat{p}_i) \tag{1}$$

其中，$N$ 为点云中的总点数，$y_i$ 为第 $i$ 个点的真实类别，$\hat{p}_i$ 为模型对该点属于真实类别的预测概率，$w_{y_i}$ 为对应类别的权重。类别权重通过对训练集进行逆频率采样估计并进行归一化得到。实际配置中，背景权重设为 $0.6$，甘蓝权重设为 $1.0$，从而迫使模型更关注甘蓝类别的语义预测误差。

对于 PointGroup 和 SoftGroup 等实例分割方法，损失函数在语义分类的基础上进一步引入了几何线索，以辅助单株实例的聚类。具体地，模型包含一个偏移量预测分支，为每个点回归一个三维偏移向量，引导其向其所属实例的中心点移动。偏移损失由两个互补的分量组成：

$$L_{offset\_norm} = \frac{1}{\sum v_i} \sum_{i=1}^{N} v_i \cdot \| \mathbf{o}_i - \mathbf{o}_i^{gt} \|_1 \tag{2}$$

$$L_{offset\_dir} = -\frac{1}{\sum v_i} \sum_{i=1}^{N} v_i \cdot \frac{\mathbf{o}_i}{\|\mathbf{o}_i\|_2} \cdot \frac{\mathbf{o}_i^{gt}}{\|\mathbf{o}_i^{gt}\|_2} \tag{3}$$

其中，$\mathbf{o}_i$ 和 $\mathbf{o}_i^{gt}$ 分别为第 $i$ 个点的预测偏移向量和真实偏移向量，$v_i \in \{0, 1\}$ 为有效性掩码，用于排除忽略标签的点（如标签为 $-100$ 的点）。式 (2) 通过 $L_1$ 范数惩罚偏移量大小的偏差，式 (3) 则通过预测偏移方向与真实偏移方向之间的负余弦相似度来约束方向一致性。

此外，在预训练阶段之后（$epoch > 128$），引入候选提案评分分支，用于评估候选实例提案的质量。评分损失定义为预测评分与真实评分之间的二值交叉熵，其中真实评分由各提案与真实实例之间的交并比（IoU）计算得到：

$$L_{score} = -\frac{1}{M} \sum_{j=1}^{M} \left[ s_j^{gt} \log(\sigma(\hat{s}_j)) + (1 - s_j^{gt}) \log(1 - \sigma(\hat{s}_j)) \right] \tag{4}$$

其中，$M$ 为提案数量，$\hat{s}_j$ 为第 $j$ 个提案的原始预测评分，$\sigma(\cdot)$ 为 Sigmoid 函数，$s_j^{gt}$ 为分段化的真实评分。真实评分通过对各提案与所有真实实例的最大 IoU 进行阈值分段得到：前景阈值 $0.75$，背景阈值 $0.25$，区间内线性插值。

最终的总损失函数为上述各分量的加权和：

$$L_{total} = \lambda_1 L_{wCE} + \lambda_2 L_{offset\_norm} + \lambda_3 L_{offset\_dir} + \lambda_4 L_{score} \tag{5}$$

其中 $\lambda_1$、$\lambda_2$、$\lambda_3$、$\lambda_4$ 分别为各损失项的权重系数。对于 PointGroup 和 SoftGroup 配置，四个权重均设为 $1.0$，即各监督信号平等对待。对于纯语义分割变体（PointNet2），仅激活语义损失，$\lambda_1 = 1.0$，$\lambda_2 = \lambda_3 = \lambda_4 = 0$，此时总损失退化为类别加权交叉熵损失。
